## F09 / T009: user logout (#19)

URL: `account/logout`; protected account URL: `account/account`. Prerequisite: validated F02 login and a configured dedicated account. Each scenario signs in independently in a fresh browser and checks the account route and sidebar logout link before exercising logout. A failed sign-in is recorded as a setup error. Missing credentials cause a skip.

Logout must end the authenticated session, protect subsequent account access, and allow the user to authenticate again. These checks exercise session behaviour beyond simply finding a logout button.
